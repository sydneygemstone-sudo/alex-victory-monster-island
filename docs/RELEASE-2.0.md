## Implementation
The new view retains the web 6Pro procedural visual foundation. Combat is a separate authoritative rules module shared by solo and the LAN server. Environmental stone lifting, enlarged touch controls, locked battle territory, ranged guardian attacks, a non-graphic intro, procedural music/effects, crystal upgrades and the Heavy ability implement the classroom feedback. Two-player guardian health is exactly twice the corresponding solo encounter (first encounter: 960 / 1920). Remote attacks cover both players. Local co-op requires Node and both devices reaching that server; the public static site is solo-capable, not a hosted multiplayer backend.

## Verified vs pending

Those are release gates for a production claim. Current label remains beta. Earlier original 6Pro screenshots are labelled as original-foundation images, not as new-version acceptance evidence.
