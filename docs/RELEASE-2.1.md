# Monster Island 2.1 — delivery and review

## 本轮实际变更

Alex 的普通电攻击重做为真实飞行电磁弹：炮体、线圈、实体弹丸、拖尾、命中粒子和碰撞后扣血。普通基础伤害 30，超载 130。Victory 抓石投掷 74、重力场 70；页面数值直接对应规则，不再展示错数。

首胜解锁的重压改为选择落点、跃起、下落与地面压砸。中心基础伤害 260，外圈 62%，可失误打空；取消瞄准不消耗冷却。屏幕震动可减少，伤害与详细血量数字可关闭。

怪物重压也有预警、起跳、飞行与落地冲击，落地才造成伤害。冲刺有身体前倾、扬尘和轨迹表现；战斗中的咆哮与开场均有声效。

36 秒的八段开场依次展示下船、接近山洞、藏身、五头蛇闯入、咆哮、挑衅、吞噬与交回控制。动画为原创程序化游戏演出，不含血腥。3.1 秒咆哮 WAV 为原创合成占位，后续可以换成学生生成的音频。浏览器成功解码不等于已在实体 iPad 上完成听感验收。

首页最先显示预算与人工重建估算；完整九张入口卡对应游戏、分镜、四版比较、账本、开发日志、家长说明、双人指南、测评和完整下载。支持简体中文、繁体中文与英文。

## 评分复盘

旧评分混淆了“功能存在”和“呈现出色”。能扣血、有角色、能通关是玩法闭环证据，不应抬高美术分；反过来，优秀美术也不能免除严重触控问题。新版比较页按美术、交互、闭环、清晰度分别给分，并解释每次加减分。这是本次作品的主观评审，不是学生能力评估或客观模型排名。

课堂 MVP 使用美术 40%、手感 30%、闭环 20%、清晰度 10% 的公开权重。按时提供可玩物的价值单列；没有首个可玩版本计时的版本不捏造分钟数进行排名。MVP 不是生产稳定性验收。

外部基准来自发布方报告，未在本项目重跑。相近的编码分数不能解释全部美术差距。不同环境、提示、推理档位、工具、时间分配和回归覆盖共同影响成品；本次四份样本不能识别“模型贡献百分比”。尤其不把 Terminal-Bench 2.1 和 4.0 放进同一排行榜。

## 计量与成本

完整数据和来源：data/costs-2.1.json；在线可视化：costs.html。

三份 CLI 会话按照实际 Token、缓存读写和标准 API 价格复算，合计 A$18.3606266844，占 A$100 预算的 18.3606266844%。其中 GLM A$0.7756133492、Codex Astra A$5.8741016283、Opus A$11.7109117069。它是 API 等值核算，不是订阅账号的额外扣款账单。

Opus 按 53 个唯一消息请求去除流式重复；缓存写入为 1 小时。Codex 输入总数先扣除缓存部分。推理是输出的子集，没有加第二次费用。Astra 最大单次输入 106,434，小于 272K 长上下文价格阈值。

网页原稿、2.0、2.1 的请求 Token 未取得回执，金额为 null，不能视为免费。当前无法证明全项目只花了 A$18.36，也不能将 A$81.64 称为可用余额。代码长度和文件大小不充当计费 Token。

人工重建估算为一次重建最终成品的 92 小时 × A$63.4362348178/h ≈ A$5,836.13。工时为任务拆分估算，工资基准来源和计算假设列于账本，不是实际采购报价、游戏估值或真实人工账单。

## 验收边界

- 29 项 Node 规则与 HTTP/SSE 联机回归通过，包括两角色规则驱动战斗获胜、投射物延迟命中、瞄偏打空、取消、暂停、双人开场同步及断线。
- 20 项 Chrome 渲染场景检查通过。为捕捉发射与首帧之间的状态，一项使用原子 DOM 键盘事件；其余技能使用 Playwright 键盘控制。测试有明确的位置、解锁和时间推进设置，不冒充实体设备或人类通关。
- 八页网站完成三语、图片和溢出检查；首页额外检查 390 像素移动视口。
- 四份原作完成启动截图检查，不代表本轮对每份原稿做了全流程通关。
- 未验收：实体 iPad / Safari、不同家庭公网双人。在线静态站单人可用；双人需同 Wi-Fi 本地 Node 服务。

机器可读最终结果：data/acceptance-2.1.json。历史 2.0 的说明、截图和报告只对应旧版；本文件与 2.1 数据为当前说明。
